# Three-minute demo script

Use the built-in Clinical Intake sample for the first recording. Keep the browser window and the exported files visible; no account or external service is needed for the demo.

1. **0:00–0:25 — Import and readiness.** Load the sample and point out the maturity score, review blockers, source count, and readiness status.
2. **0:25–1:05 — Grounded nodes.** Select a node and show its source IDs, objective, acceptance conditions, provenance, and the generated model-specific execution package.
3. **1:05–1:40 — Mixed-model graph.** Show the Flexible Talent, Challenge, and Private Pod distribution, then walk across the DAG, waves, and critical path.
4. **1:40–2:15 — Human review.** Edit a node, split or merge it, override one operating model, and add or remove a dependency. Show the change-impact panel; attempting a cycle is rejected by the editor.
5. **2:15–2:45 — Quality gate.** Run the gate and point out source coverage, model completeness, dependency checks, cycle detection, readiness, and critical-path status.
6. **2:45–3:00 — Export.** Export the graph JSON and human-readable execution plan. End by showing the mock-mode label and the four sample output folders.

Suggested narration: “The imported package remains the primary source. Recommendations are labelled, user decisions are recorded, and deterministic graph checks decide whether the execution package is ready for handoff.”
